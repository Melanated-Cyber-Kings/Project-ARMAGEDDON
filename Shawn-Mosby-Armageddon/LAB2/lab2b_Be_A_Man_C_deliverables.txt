3. Explanation of RefreshHit
CloudFront had a cached copy of the object, but the TTL expired (or revalidation was triggered). 
Instead of a full refetch (Miss), CloudFront sent a conditional request to the origin using the If-None-Match (ETag) validator. 
The origin responded with a 304 Not Modified, signaling that the content hasn't changed. 
CloudFront then reused the existing cached body, saving bandwidth and reducing origin load.

4. Injection B: Analysis & Resolution
Scenario: Content is changed at the origin, but the ETag/Validator remains the same. 
Observed Result: CloudFront continues to receive a 304 Not Modified and serves stale content to users (perpetual RefreshHit).

Chosen Fix: Update the ETag. 
Justification: Updating the ETag is the correct architectural fix. 
    It maintains the "Origin as Source of Truth" and allows the HTTP protocol to handle cache freshness naturally. 
    While an invalidation (Honors+) works, it is an emergency manual operation. 
    Updating validators is a programmatic, scalable solution that ensures zero-downtime consistency.

5. Final One-Paragraph Takeaway
What does RefreshHit mean, and why is it often better than a Miss? 
    A RefreshHit indicates that the CDN successfully confirmed with the origin that its cached version is still valid using a conditional GET request. 
    It is superior to a Miss because it drastically reduces egress bandwidth—the origin only sends a small header response rather than the entire file payload. 
    This reduces the "thundering herd" effect on the origin and lowers latency compared to a full refetch, while still providing a guarantee that the user is not seeing stale content.

The Thundering Herd Effect: 
    This occurs when a popular cached object is invalidated globally or expires simultaneously across all edge locations. 
    This forces every edge location to send a request back to the origin at once, potentially overwhelming the ALB and EC2 servers with a massive spike in traffic that can lead to increased latency or system failure.
